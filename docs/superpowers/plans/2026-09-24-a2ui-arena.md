# Shared A2UI Arena Implementation Plan

> **For agentic workers:** Inline execution in this session; verify each task before continuing.

**Goal:** Give every live tool-call lane the same A2UI result surface so model speed comparisons retain a common UI.

**Architecture:** A shared server-independent builder maps each validated tool execution to an A2UI v0.9 data model and fixed component tree. A client component passes the messages to CopilotKit's A2UI renderer and offers a fixed React view for inspection.

**Tech Stack:** React, CopilotKit A2UI renderer, Zod, Vitest, Next.js.
