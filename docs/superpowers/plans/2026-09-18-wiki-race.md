# Wiki Race Implementation Plan

> **For agentic workers:** Use executing-plans to implement the checklist in this session.

**Goal:** Build a runnable CopilotKit + Jev Wikipedia race with visible, verifiable hops.

**Architecture:** A custom AG-UI agent runs concurrent model lanes and emits complete race snapshots. CopilotKit drives the frontend directly from those snapshots. Wikipedia retrieval, model decisions, and deterministic game rules are separate modules with injectable interfaces.

**Tech Stack:** Next.js, TypeScript, CopilotKit 1.72 v2 exports, AG-UI, Zod, RxJS, Vitest, CSS.

## Acceptance commands

```sh
pnpm install --frozen-lockfile
pnpm test
pnpm typecheck
pnpm lint
pnpm build
pnpm dev
```

Visit http://localhost:3000, choose Sample, start a race, inspect its path, stop another race, and restart. For live Jev, set `TYPESAFE_API_KEY` in `.env.local`; optional comparison lanes use `OPENROUTER_API_KEY`. Missing keys must be reported visibly rather than replaced with fixture answers.
